# Homebrew Tap for PollutionTracker

A macOS menu bar app that tracks real-time air pollution levels (AQI) for your current location.

## Installation

```bash
brew tap macjul003/pollutiontracker
brew install --cask pollution-tracker
```

## Updating

```bash
brew upgrade --cask pollution-tracker
```

## Uninstalling

```bash
brew uninstall --cask pollution-tracker
brew untap macjul003/pollutiontracker
```
